3线程模型与并发安全

LVGL 非线程安全：所有 UI 更新只在主循环线程；后台线程只写"数据缓存"，UI 定时器搬运到控件。
线程数量启动条件周期/行为停止方式对外共享数据（锁）
main 1 常驻 LVGL 主循环 lv_timer_handler + usleep(5ms) 退出程序 全部 UI 对象
camera_thread 0~1 实时画面界面点"开启摄像头" camera_capture_frame() + 按 fps 节流 cam_thread_stop → join V4L2 双缓冲 frame_lock
ai_thread 0~1 点"ai识别"按钮（需摄像头已开） 快照→推理→缓存结果，200ms/帧 ai_thread_stop → join g_latest_result g_result_lock
gy39_thread 0~1 目前由设置开关控制（配置项 env_monitor_enabled） 阻塞读串口 → 组帧解析 gy39_thread_stop → join latest_lux/env gy39_data_lock
server_thread 0~1 服务器界面点"启动服务器" 阻塞 accept（detached） 关闭 listen fd 唤醒退出 —
每连接 recv/send 0~128 新客户端 accept 成功 recv 阻塞解包分发；send 轮询发送队列 关 fd → join 发送队列 send_mtx · 写 socket socket_mtx
关键并发规则：
① 文件数据直发（P2P 中转 / 上传 / 下载）必须持 socket_mtx，绕过发送队列，防止 256KB 分片撑爆 32 格队列；
② 客户端管理器 g_mgr.mtx 保护链表增删改查；server_shutdown 防重入，关闭后禁止再调 client_mgr_*；
③ 摄像头"锁外转换"设计：YUYV→ARGB 在 frame_lock 外计算，切换索引时再上锁，避免阻塞 UI 读帧；
④ 全局配置 g_app_config 无锁，按"启动后只读 + 设置页单线程写"约定使用。
